# **App Name**: Monopoly Manager

## Core Features:

- Salary Input: Allow users to input their salary.
- Passive Income Input: Allow users to input their passive income sources.
- Total Income Calculation: Automatically calculate total income by summing salary and passive income.
- Expense Input: Allow users to input their monthly expenses.
- Monthly Cash Flow Calculation: Calculate monthly cash flow by subtracting total expenses from total income.
- Cash Flow Forecast: AI tool analyzes historical income and expense data to forecast future cash flow trends.

## Style Guidelines:

- Primary color: Dark purple (#673AB7) for sophistication and reliability.
- Background color: Very light purple (#F3E5F5) for a soft, calming background.
- Accent color: Deep blue (#3F51B5) to complement purple tones and add depth.
- Body and headline font: 'PT Sans', a humanist sans-serif offering a modern look with a touch of warmth, suitable for both headlines and body text.
- Column-based layout for clear organization on mobile.
- Use simple, clear icons to represent income and expense categories.
- Subtle animations to indicate changes in cash flow.
